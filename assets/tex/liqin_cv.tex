\section{\textbf{Research Project}}
\vspace{-0.4mm}
\small
  \resumeSubHeadingListStart
  \resumeSubheadingProjectExperience
    {Multi-Step Reinforcement Learning for LLM Forecasting Agent}{May 2026 - Present}
    \resumeItemListStart
    \item Formulated real-world event forecasting as sequential posterior approximation, training an LLM agent to continuously revise probabilistic beliefs as new evidence arrives rather than make one-shot predictions
    \item Designed a leak-free temporal POMDP over a daily-sliced news corpus, enabling date-restricted \textsc{Search}/\textsc{Scrape}/\textsc{Code} interactions and a structured rolling belief notebook for long-horizon evidence tracking
    \item Built an end-to-end data pipeline to curate resolving real-world questions using temporal contamination controls, hybrid BM25/dense retrieval, news-dynamics filtering, and LLM-based corpus solvability checks
    \item Improved GLM-4.5-Air (106B, 12B active) forecast accuracy from 39.8\% to \textbf{45.5\%} and Brier score from 0.751 to \textbf{0.721}
    \resumeItemListEnd

  \resumeSubheadingProjectExperience
    {Evolutionary Task Discovery for LLM Reasoning}{Jun 2025 - Jan 2026}
    \resumeItemListStart
      \item Formulated reasoning data generation as directed search over a manifold of algorithmic skill and complexity
      \item Designed two evolutionary operators, Attribute Mutation for complexity scaling and Skill Crossover for compositional logic discovery, with a dynamic Zone of Proximal Development filter to ensure learnability
      \item Achieved \textbf{+5.7\%} on code and \textbf{+6.4\%} on math benchmarks over Qwen3-4B Thinking, with up to \textbf{+8.2\%} on competition-level AIME problems; consistent gains in both pass@1 and pass@8 confirm no diversity collapse.
      \item Validated effectiveness and scalability on Base models (Qwen3-4/8B) and Instruct models (LLaMA-3-3/8B)
    \resumeItemListEnd

  \resumeSubheadingProjectExperience
    {Precise Attribute Intensity Control in LLMs}{Nov 2024 - May 2025}
    \resumeItemListStart
      \item Developed a test-time gradient-based representation editing method (PRE-CONTROL) that steers LLM's hidden states toward multi-dimension attribute intensity targets in closed-form to meet diverse user preferences
      \item Implemented TD-$\lambda$ training for a lightweight value function to approximate faithful partial sequence reward
      \item Achieved \textbf{6.6-30.7\%} exact target-hit success (up to \textbf{5.1x} over best baseline) on both text and code generation tasks
      \item Improved Pareto frontier hypervolume from 7.54 to \textbf{12.66} while reducing \textbf{8x} computational overhead
      \item Designed a controllable distillation pipeline using PRE-CONTROL, reaching higher Pareto hypervolume (\textbf{16.81} vs.\ 15.27) with only \textbf{15k} vs.\ 50k samples and \textbf{2.1} vs.\ 7.8 GPU hours compared to Best-of-$N$ distillation
    \resumeItemListEnd

  \resumeSubheadingProjectExperience
    {Calibrating Pre-trained Classifiers on LLM-generated Noisy Labels}{Sep 2023 - May 2024}
    \resumeItemListStart
    \item Developed label candidate retrieval in embedding space to obtain faithful true labels for noisy samples
    \item Stabilized the training of true label generative modeling via label candidates distillation algorithm
    \item Designed a Simplex Label Diffusion Model to recover true labels from noisy labels via iterative denoising process
    \item Improved BERT accuracy by \textbf{7.3\%} on average across 4 NLP tasks and 5 LLMs annotated labels, and up to \textbf{11.7\%} over raw LLM predictions and \textbf{4.5\%} over the best noisy-label baseline on SemEval.
