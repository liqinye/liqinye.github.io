{%- comment -%} Renders an author list. Params: authors (array), max (int, default 10), count (bool: append "(n authors)"), nowrap (bool: wrap each name in span.nowrap so a surname never lands alone on the next line — /publications/ passes it). Up to `max` authors are listed in full. Longer lists are elided but ALWAYS keep the last author and the owner (.self): the first three, "…", the owner if not already shown, "…", the last author — e.g. "Liqin Ye*, Haorui Wang*, Fardin Ahmed, … Chao Zhang" or "Michael Galarnyk, Siddharth Lohani, Vidhyakshaya Kannan, … Liqin Ye, … Sudheer Chava". Elision is only for narrow text columns: cards pass max=6; /publications/ (full-width line) passes max=100 = everyone; count=true (unused now) appends "(n authors)". Each "…" is a button (.authors__more) that reveals the full list, kept in span.authors__full next to the short one (one-way; script at the end of footer.html). {%- endcomment -%} {%- assign authors = include.authors -%} {%- assign max = include.max | default: 10 -%} {%- assign n = authors | size -%} {%- capture eq -%}* (equal contribution){%- endcapture -%} {%- capture full -%} {%- for a in authors -%} {%- if a.self %}{{ a.name }}{% elsif include.nowrap %}{{ a.name }}{% else %}{{ a.name }}{% endif -%} {%- if a.equal %}{{ eq }}{% endif -%} {%- unless forloop.last %}, {% endunless -%} {%- endfor -%} {%- endcapture -%} {%- if n <= max -%} {{- full -}} {%- else -%} {%- assign gap = false -%} {%- for a in authors -%} {%- if forloop.index0 < 3 or forloop.last or a.self -%} {%- if gap %} {% endif -%} {%- assign gap = false -%} {%- if a.self %}{{ a.name }}{% elsif include.nowrap %}{{ a.name }}{% else %}{{ a.name }}{% endif -%} {%- if a.equal %}{{ eq }}{% endif -%} {%- unless forloop.last %}, {% endunless -%} {%- else -%} {%- assign gap = true -%} {%- endif -%} {%- endfor -%} {%- if include.count %} ({{ n }} authors){% endif -%} {{ full }} {%- endif -%}
